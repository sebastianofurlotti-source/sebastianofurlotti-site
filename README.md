# sebastianofurlotti.com

Sito personale di Sebastiano Furlotti — serie *Timbri*.

Sito statico, single-file, no build. Aprire `index.html` direttamente.

## Struttura
- `index.html` — pagina unica (galleria + biografia + footer)
- `web/` — 57 JPEG ottimizzati (max 1800px)
- `thumbs/` — 57 thumbnail (max 800px)
- `_redirects` — redirect dai vecchi URL Adobe Portfolio
- `robots.txt`, `sitemap.xml` — SEO

## Deploy
Cloudflare Pages, deploy automatico ad ogni push su `main`.
